# Fathom AI Assignment

The first implementation slice of a Fathom-inspired meeting intelligence workspace. It includes a responsive application shell, a searchable meetings dashboard, realistic seeded meeting records, and intentionally limited meeting-detail placeholders.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Checks

```bash
npm run lint
npm run build
```

The project uses Next.js, TypeScript, Tailwind CSS, and Lucide icons. The webpack flags in the development and build scripts keep CSS compilation reliable in restricted local environments.
